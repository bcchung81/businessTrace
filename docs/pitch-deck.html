연번과제현황영향
1 재무 데이터의 구조적 결측 비상장 · 비외감 기업은 재무제표 공시 의무가 없어 원천 자체에 자료가 없음. DART 재무 확보 13 / 56 (23%) 정량 비교 항목이 일부 기업에서 공란이 되어 조달 실적 · 벤처확인 · 고용 규모 등 대리지표로 보완 중
2 검토 필요 건의 확인 부하 검증 119건 중 16건(13.4%)이 담당자 확인 대상으로 분류됨. 판정을 가르는 지표는 어휘 일치도(평균 0.686) 확인 건수가 증가할 경우 담당자가 일괄 승인하게 되어 검증이 형식화될 소지가 있음
3 운영 환경 미전환 개발용 데이터베이스(SQLite)로 동작 중이며, 배포용 컨테이너는 작성 완료했으나 이미지 빌드 검증이 미완료 상태 다수 이용자 동시 접속 및 정식 운영 배포에 앞서 데이터베이스 전환과 배포 검증이 선행되어야 함
4 운영 인력의 단일화 과제 내 AI 활용 부분을 개인프로젝트 형태로 구축하여 설계 · 운영 지식이 1인에게 집중되어 있음 담당자 변경 시 유지보수 연속성 확보가 필요하며, 타 부서 확산에도 인수인계 체계가 전제됨
