## 검증 과정 (코드 기준)

분석이 끝난 기업마다 `verifyAnalysis` 가 4층을 돈다. judge 만 LLM 이고 나머지는 코드다.

1. **출처 인용** — 인용 가능한 링크(http(s)·차단 언론사 아님)의 비율. 문턱 0.5
2. **근거 충실도(LLM judge, effort low)** — 종합의견·기사 요약에서 주장을 뽑아 원문과 대조. 공공데이터 사실 줄(`publicFactLines`)도 함께 넘긴다. 통과 주장 비율, 문턱 0.85
3. **근거 일치** — 요약 어휘가 원문에 들어 있는 정도(containment). LLM 없이 judge 의 오판을 거르는 독립 신호. 문턱 0.5
4. **반증** — judge 가 같은 호출에서 "이 평가가 틀릴 수 있는 이유"를 낸다

세 문턱을 모두 넘으면 verified, 하나라도 못 넘으면 needs_review, judge 가 답을 못 내면 failed 다.
