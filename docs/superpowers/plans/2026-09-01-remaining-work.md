## 2. 결정이 있어야 움직이는 것

### 2-1. SQLite → PostgreSQL

지금은 SQLite 다. 옮기려면 코드 변경이 따른다. 비용을 보고 판단할 것 — 절차는 `deploy/README.md` 하단에 적어 뒀다.

1. `prisma/schema.prisma` 의 `provider` 교체
2. 어댑터를 `@prisma/adapter-better-sqlite3` → `@prisma/adapter-pg` (`src/lib/db.ts`)
3. **기존 마이그레이션은 SQLite 방언이라 재사용할 수 없다** — 전부 재생성
4. 테스트가 `file:./prisma/test.db` 를 쓰므로 테스트용 PG 인스턴스도 필요
5. compose 에 `postgres` 서비스·healthcheck 추가

### 2-2. `.env.example` 이 git 에 없다

`.gitignore` 의 `.env*` 패턴에 걸려 추적되지 않는다. 로드맵은 "키 이름을 유지"하라고 적고 있어 의도와 어긋난다.
값이 전부 비어 있어 커밋해도 안전하다 — `!.env.example` 예외를 넣을지 정할 것.

### 2-3. 화면 문구 잔여
